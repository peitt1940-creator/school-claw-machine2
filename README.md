# 校園闖關夾娃娃抽獎系統

## 玩法
資優班期末兌獎活動用的夾娃娃抽獎機。

1. 學生輸入姓名和 4 碼亂碼條代碼，按「啟動夾爪」。
2. 夾爪移動、下降到球堆裡抓球，再拉回洞口。
3. 夾到小球是普通獎、大球是大獎，半路掉球就是「銘謝惠顧」，學生憑結果向工作人員領獎。
4. 每張亂碼條只能用一次。結果由代碼事先決定，夾爪動畫只是演出。

### 老師後台（需密碼）
- 設定獎品清單（普通獎、大獎、銘謝惠顧）與數量，產生對應的亂碼。
- 匯出 Word 檔：學生用的代碼條（每列 3 張），老師用的抽獎檢核表（含獲獎人簽名欄）。
- 換裝置時，先「下載設定檔」備份，再到另一台裝置「讀取設定檔」還原。
